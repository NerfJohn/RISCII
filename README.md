# Project RISCII
*"Semi-casual project to design a dev kit from scratch"*

## Purpose

To have fun casually designing/creating a dev kit- seeing how far I can vertically design a functional embedded system.

---

## Intro

Project RISCII (pronounced "risky"- not to be confused with RISC-II) is a personal passtime project focused on the various layers of embedded system design. These levels include:

- Level 5: OS Design
- Level 4: Firmware Design
- Level 3: Compiler/Toolchain Design
- Level 2: Processor/Digital Design
- Level 1: PCB Design

This project is not meant to be a serious implementation, nor has any direct usage beyond a passtime. If there is potential educational or professional use, the material is free to use (at the risk of the user).

## General Approach

This project is approached from a "bold fun/learning" philosophy. There is little pressure to create professional grade designs/documents, though approaches should have some basis in reality and include some documentation. Overall, this project should be a place to comfortably experiment, redo, have fun, and learn by doing vs learn by AI prompting (give or take niche scenarios).
